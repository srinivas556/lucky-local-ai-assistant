Built with intent

Small foundation.
Big learning journey.

Lucky starts with the essentials: a local model, a reusable system prompt, and a simple conversation loop. Each part is a building block for future experiments.

⌘

Local LLM integration

Connect Python to a language model served locally by Ollama, without depending on a cloud LLM API for inference.

✳

Prompt engineering

Keep the assistant's system instructions in a separate file, making behavior easier to inspect, refine, and evaluate.

↔

Interactive text chat

Ask questions from the terminal and receive responses from the locally configured model.

⚙

Configurable setup

Choose a model and configure the Ollama server URL using environment-based settings.

⌁

Modular Python

Separate the assistant, configuration, LLM client, prompts, tools, and memory into distinct modules.

◈

Versioned development

Build in small, understandable milestones, with each release documenting what works and what comes next.

Scope note: This website describes v0.1.0 as the text-based release. Voice interaction, tool execution, persistent memory, and computer automation are roadmap items until implemented and tested in a later release.

A key learning area

Prompt engineering is more than asking a question.

The system prompt sets a default role and response guidelines. A major goal for future versions is to evaluate how different instructions affect clarity, consistency, and constraint-following.

System promptsInstruction clarityContextEvaluation
system_prompt.txt

ROLE
You are Lucky, a local AI personal assistant.

STYLE
Be clear, helpful, and practical.

RELIABILITY
Do not claim actions were performed unless a tool actually performed them.

DESIGN PRINCIPLE
Keep instructions separate from application logic.
